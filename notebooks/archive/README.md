# Archive: the single-notebook version (v3.2)

`insurance_policy_rag_v3_2.ipynb` is the whole system and its evaluation in one Colab notebook, as it was before the
package. The published answers were generated by its predecessor, v3.1, whose answering code is identical. The
package in `src/policy_rag/` was ported from this notebook and verified to give the same results
([docs/evaluation.md](../../docs/evaluation.md#verification)).

It is kept for reference and is no longer maintained. Use the package, or `notebooks/colab_quickstart.ipynb`.
